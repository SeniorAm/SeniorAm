### الان روی چه کار می‌کنم

راهنمای وصل کردن شاپ سرور به **زرین‌پال، زیبال، آیدی‌پی** و درگاه ارزی.  
بازیکن می‌خرد، API درگاه verify می‌کند، آیتم همان لحظه می‌رود تو دیتابیس. ادمین وسط نیست.

**[game-server-payment-gateways](https://github.com/SeniorAm/game-server-payment-gateways)** — فارسی و English، با خروجی واقعی API.
